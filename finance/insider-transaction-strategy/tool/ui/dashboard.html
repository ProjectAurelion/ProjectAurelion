For the cleanest no-CSV workflow, keep insider download mode on and switch the market-data provider to FMP API with your key. If the API key field is blank, the server will also look for MARKET_DATA_API_KEY or FMP_API_KEY.

Uploaded files take priority over local paths. Uploading an insider CSV skips the SEC download step. Uploading a prices/reference CSV skips the API/public downloader. The profile and optional mapping JSON help normalize richer vendor exports when you do use files.
